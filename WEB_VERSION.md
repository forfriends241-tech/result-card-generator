# 🚀 Result Card Generator - Web Version

**अब बिना किसी installation के browser में सीधे result cards बना सकते हो!**

## ✨ क्या करता है:

✅ **No Installation** - सीधे browser में खुल जाएगा  
✅ **Data Entry** - Form में student details और marks डालो  
✅ **Auto Calculate** - Total, percentage, grade automatically calculate होंगे  
✅ **PDF Download** - Professional PDFs download करो  
✅ **Local Storage** - सभी data browser में save रहेगा  
✅ **Offline Mode** - internet के बिना भी काम करेगा  

---

## 🎯 कैसे Use करें:

### Step 1: Download करो
```bash
git clone https://github.com/forfriends241-tech/result-card-generator.git
cd result-card-generator
```

### Step 2: Open करो
Browser में `index.html` को खोलो:
- **Windows**: `index.html` पर double-click करो
- **Mac/Linux**: `index.html` को browser में drag करो
- **या** Right-click → "Open with Browser"

### Step 3: Data Enter करो
1. School details भरो (पहले से filled है)
2. Student name, marks आदि डालो
3. "Add Student" button दबाओ

### Step 4: PDFs Download करो
- Single PDF: "Download" button
- All PDFs: "Download All PDFs" button

## 🆘 Troubleshooting

### Browser में खुल नहीं रहा
- File को `.html` extension के साथ save करो
- सही browser use करो
- File को admin mode में खोलने की try करो

### Data save नहीं हो रहा
- Browser cache clear करو
- Private/Incognito mode use न करो
- Cookies enable होने चाहिए

### PDFs download नहीं हो रहे
- Pop-up blocker check करो
- Browser console देखो (F12)
- JavaScript enable करो
